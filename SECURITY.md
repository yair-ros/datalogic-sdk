# Security Policy

## Supported Versions

Security fixes are best-effort for the latest release on `main`.

## Reporting a Vulnerability

Do not open a public GitHub issue for vulnerabilities that expose:

- API tokens
- customer data
- shipping labels
- order or address data

Use GitHub's private vulnerability reporting for this repository if it is
enabled. If it is not enabled, contact the repository owner privately before
publishing details.

Include:

- affected version
- steps to reproduce
- impact
- whether real credentials or customer data are involved

## Scope

This repository is an independent/community SDK for the Datalogics API. Reports
about the upstream Datalogics platform itself may also need to be disclosed to
Datalogics directly.

If the issue is in the Datalogics platform or account environment rather than in
this SDK, open a Datalogics support ticket:

- [Datalogics support ticket](https://docs.datalogics.co.il/support-ticket/)
